# Part 8 - Intro to Full-Stack Web Development

---

## What Does Full-Stack Mean?

**Full-stack development** means building both sides of a web application:

- **Front end (client side):** what users see and interact with
- **Back end (server side):** logic, data, and security behind the scenes

In this course, you will connect both sides into one working system.

---

## Client Side vs Server Side

| Client Side                 | Server Side                         |
| --------------------------- | ----------------------------------- |
| Runs in the browser         | Runs on a server                    |
| HTML, CSS, JavaScript UI    | App logic, APIs, database work      |
| Focus: user experience      | Focus: data, rules, security        |
| Example: form validation UI | Example: save form data to database |

---

## What Is a Web Server?

A web server is software (running on a computer) that listens for HTTP requests and sends HTTP responses.

At minimum, it can:

- Receive a request (like `GET /index.html`)
- Find or generate the requested content
- Send back a response (HTML, JSON, image, error code)

Common examples: Nginx, Apache, Node/Express apps.
