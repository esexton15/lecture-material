## Von Neumann Architecture Overview

In 1945, John von Neumann described a stored-program computer model that is still the foundation of modern computers.

Key idea:

- A program is **stored in memory** alongside data
- The CPU fetches, decodes, and executes instructions one at a time
- This is called the **fetch-decode-execute cycle**

Nearly every computer you use today is built on this model.

---

## Components of a Von Neumann Computer

A simple Von Neumann computer has four main components:

- **Central Processing Unit (CPU)** — processes instructions
- **Main Memory (RAM)** — stores programs and data
- **Input/Output (I/O) Devices** — interact with the outside world
- **System Bus** — connects all components and transfers data

---

## The CPU — Main Components

The CPU is the "brain" of the computer. It contains three main parts:

- **Control Unit (CU)** — directs the flow of instructions and coordinates components
- **Arithmetic Logic Unit (ALU)** — performs calculations and comparisons
- **Registers** — small, fast storage locations inside the CPU

---

## The Arithmetic Logic Unit (ALU)

The ALU is responsible for all computation inside the CPU.

Arithmetic operations:

- Addition, subtraction, multiplication, division

Logical operations:

- AND, OR, NOT
- Comparisons (greater than, equal to, less than, etc.)

The ALU receives operands from registers, performs the operation, and sends the result back to a register.

---

## CPU Registers

Registers are the fastest storage in a computer. Common CPU registers:

| Register                      | Purpose                                         |
| ----------------------------- | ----------------------------------------------- |
| Accumulator                   | Holds intermediate ALU results                  |
| Program Counter (PC)          | Holds the address of the next instruction       |
| Instruction Register (IR)     | Holds the currently executing instruction       |
| Memory Address Register (MAR) | Holds the address of memory to access           |
| Memory Data Register (MDR)    | Holds data being read from or written to memory |

---

## The Accumulator

The **accumulator** is a special-purpose register in the ALU.

- Holds the result of the most recent arithmetic or logical operation
- Acts as the default operand and destination for ALU calculations
- Intermediate results are stored here as computations are chained together

Example — calculating `3 + 4 + 2`:

1. Load 3 → accumulator = **3**
2. Add 4 → accumulator = **7**
3. Add 2 → accumulator = **9**

---

## How It All Connects

Data flows through a Von Neumann computer like this:

1. Input device sends data to **main memory**
2. CPU **Control Unit** fetches the next instruction from memory
3. Instruction is decoded and sent to the **ALU**
4. ALU performs the operation, stores result in the **accumulator**
5. Result is written back to **memory** or sent to an **output device**

This cycle repeats for every instruction in the program.

## Payroll Calculations

| Calculation  | Rule                                |
| ------------ | ----------------------------------- |
| Regular Pay  | Hourly rate × hours (up to 40)      |
| Overtime Pay | Hours over 40 × hourly rate × 1.5   |
| Gross Pay    | Regular pay + overtime pay          |
| State Tax    | 5.6% of pre-tax gross pay           |
| Federal Tax  | 7.9% of pre-tax gross pay           |
| Post-Tax Pay | Gross pay − state tax − federal tax |
