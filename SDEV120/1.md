## Catalog Description in Plain Language

You will learn how to design algorithms, represent logic, and implement simple scripts.

Major focus areas:

- Flowcharting, pseudocode, UML
- Control structures and operators
- Number systems and data representation
- Testing, debugging, and secure design thinking
- Computer architecture and logic gates

---

## Course Content Topics

- Algorithms and algorithm development
- Flowcharting and pseudocode
- UML and logic structures
- Relational and logical operators
- Order of precedence and truth tables
- Numbering systems (binary, decimal, hex)
- Basic scripting and control structures
- Von Neumann architecture and logic gates

---

## Major Learning Objectives (Part 1)

By the end of this course, you should be able to:

- Use flowcharts, pseudocode, and UML to document logic
- Use sequence, selection, and repetition structures
- Apply relational and logical operators
- Test and debug simple programs
- Analyze program behavior with variables, expressions, I/O, and functions

---

## Major Learning Objectives (Part 2)

You will also be expected to:

- Convert between binary, decimal, and hexadecimal
- Explain real computing uses of binary/hex (data, media, networking, storage)
- Identify uses of programming and scripting languages
- Compare SDLC, iterative, and prototyping approaches
- Explain secure programming/design concepts
- Describe simple Von Neumann architecture
- Explore AND/OR/NOT/NAND/NOR/XOR/XNOR gates and simple circuits
